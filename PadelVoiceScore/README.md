# Padel Voice Score – native Kotlin/Compose

## Öffnen und APK erstellen
1. Diesen Ordner in Android Studio öffnen.
2. Gradle JDK auf **Temurin 17** oder **jbr-17** stellen.
3. Gradle-Sync abwarten.
4. `Build > Build App Bundle(s) / APK(s) > Build APK(s)`.
5. APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Funktionen
- Native Jetpack-Compose-Oberfläche, responsiv für Hoch-/Querformat und Tablets
- Native Android-Spracherkennung mit automatischem Neustart
- Punkte, Spiele und Sätze
- Aufschlaganzeige wechselt nach jedem Punkt
- Rückgängig, neues Match, Vollbild-Großanzeige
- Lokale Sicherung von Spielstand und Historie
- Display bleibt während des Spiels aktiv
